# Tales of Ruins: Obscure Knight

## Game Description

**Tales of Ruins: Obscure Knight** is a simple graphics project created using the **iGraphics** library in C. The project demonstrates basic graphics programming concepts like drawing shapes, handling user input, and simple animations.

## Features
- One playable character with keyboard control movements using WASD,gravity based movement jump and dash features.
- Combat System with basic attack and special attack with cooldown.
- Health bars for both player and enemies including boss displayed on the screen.
- Multiple levels with increasing difficulty with boss fight at the end including respawn limit.
- Items and Inventory can be collected for various purposes.
- Dynamic Background for each levels with sound effects for attack,walking,taking damage etc.



## Project Details
IDE: Visual studio 2010/2013

Language: C,C++.

Platform : Windows PC.

Genre : 2D light Metroidvania platformer game


## How to Run the Project

Make sure you have the following installed:
- **Visual Studio 2013**
- **MinGW Compiler** (if needed)
- **iGraphics Library** (included in this repository)


Open the project in Visual Studio 2013
- Open Visual Studio 2013.
- Go to File → Open → Project/Solution.
- Locate and select the .sln file from the cloned repository.
- Click Build → Build Solution
- Run the program by clicking Debug → Start Without Debugging


## How to Play

### **Controls**
| Player       | Move | Collect and use Items | Jump       | Attack | Dash | Slashwave Attack |
|-------------|----------|-----------|-----------|-------|------|-------|
| **Player 1** | `Left and Right Arrow`      | `2,3,4,5`       | `Space`       | `X`   | `Z`  | `Space+Arrow down`   |


### **Game Rules**

- Player starts with full health bar.
- Dash and Slashwave reduces the opponent’s stamina by 1 bar.
- Using Slashwave gives 2 seconds invincibility.
- Player can only respawn for 3 times after that the game ends.
- Player can use certain collected items from the inventory to increase health and stamina.
- Player can collect items from npc to clear levels and move to boss level.
